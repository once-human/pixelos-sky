### notes

- fastboot or recovery flash
- needs stock hyperos 2 firmware (OS2.0.210 tested)
- user build, signed, selinux enforcing
- kernel 5.10.260
- google apps included
- geekbench 7: 810 single, 2093 multi | antutu 12: 685,217 ([details](https://github.com/once-human/pixelos-sky/blob/main/docs/performance.md))

### install (fastboot)

1. bootloader unlocked, stock hyperos 2
2. platform-tools 35 or newer on your pc
3. phone in fastboot mode (power + volume down), plugged in
4. don't extract the zip, run:

```
fastboot -w update PixelOS_sky-17.0-20260930-1940-fastboot.zip
```

reboots by itself, first boot takes 5 to 10 minutes.

### install (recovery)

orangefox > format data (clean install only) > adb sideload > `adb sideload PixelOS_sky-17.0-20260930-1940.zip` > reboot. tested with [altafyafai's orangefox build](https://github.com/AltafYafai/Action-OFRP-Builder/releases/tag/25638699166).
