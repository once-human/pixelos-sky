# back to stock

1. back up your stuff, this wipes the phone
2. download the official hyperos **fastboot rom** for your phone ([firmware](firmware.md#flash-stock-hyperos-2))
3. fastboot mode (**power + volume down**), plugged in
4. flash with miflash **"clean all"**, or run `flash_all.bat` / `flash_all.sh` from the extracted rom
5. first boot takes a few minutes

## relocking

| | |
|---|---|
| staying unlocked | nothing else to do, totally fine on stock |
| want to relock | only once stock is installed **and boots fine**. never while a custom rom is on the phone |

not sure? stay unlocked.
